    Save states

    Open a game, then save your progress to a slot.

      Save stores your current progress; saving again replaces that slot. To continue later, open the same game and choose Load. Slots stay in this browser for the same emulator build. Download .sav for a backup. The Save state / Load state buttons use the selected slot, including in fullscreen.

      Input

      Keyboard

      X = A · Z = B · Enter = Start / + · WASD = move · IJKL = aim

      Keyboard, mouse & Bluetooth controller

      GameCube port 1 and Wii Remote + Nunchuk. Wii: X = A, Z = B, V/B = 1/2, Enter = +, C = −, Q/E = Nunchuk C/Z, H = Home. Keyboard: WASD main stick, IJKL C-stick, arrows D-pad, X/Z/V/B face buttons, Enter Start, Q/E triggers, C Z.

      Mouse hover tracks the Wii pointer over the play area by default, including fullscreen. No click is needed to aim. Main stick: hold and drag, release to center. Left / right / middle buttons = A / B / −.

      Simulated Wii motion: Space = Remote shake, left Shift = Nunchuk shake, numpad 4/6/8/2 = tilt left/right/forward/backward. All bindings can be changed above.

      Pair in device Bluetooth settings, then press a controller button.

      USB and Bluetooth standard controllers: face buttons A/B/1/2, left stick = Nunchuk, right stick = Wii pointer, D-pad, Start = +, shoulders/triggers = Nunchuk C/Z, Select = −, Guide = Home. GameCube mappings also work. Physical Wii Remote sensor input requires browser support; motion is simulated with the bindings above.
